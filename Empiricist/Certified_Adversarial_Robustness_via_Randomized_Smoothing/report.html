Certified Adversarial Robustness via Randomized Smoothing

Reproduction of Cohen, Rosenfeld and Kolter, ICML 2019.

datasetCIFAR-10: 32x32 colour images, 10 classes, 50,000 for training and 10,000 for test. Each image is 3x32x32 = 3,072 numbers.
modelResNet-110, 1.73M parameters. This is f, the base classifier that gets smoothed.
certified500 test images, every 20th one, with n0=100, n=100,000, alpha=0.001.

05Cost

One RTX 4080 SUPER, torch 2.14 with CUDA 13. CIFAR-10 is kept on the GPU so the data loader is not the bottleneck.

~2 h5 models and 2,500 certified images
600 sResNet-110, 150 epochs
1.66 sper image at n=100,000

06How to run it

# train one model, 600 s
uv run python train.py --sigma 0.25 --out outputs/models/sigma_0.25.pt

# certify 500 test images at n=100,000, 830 s
uv run python certify.py --checkpoint outputs/models/sigma_0.25.pt \
    --out outputs/certify_sigma_0.25.csv

# tables and figures
uv run python analyze.py --results-dir outputs
